# CHIS — ระบบสารสนเทศสุขภาพชุมชน

## ไฟล์ในชุดนี้
- Code.gs: โค้ด Apps Script สำหรับแสดงเว็บแอปและจัดการข้อมูลใน Google Sheets
- index.html: หน้าเว็บแอปที่แสดงผ่าน HTML Service ของ Apps Script
- appsscript.json: ไฟล์กำหนดสภาพแวดล้อม เขตเวลา และสิทธิ์การเข้าถึง Spreadsheet

## วิธีติดตั้งหรืออัปเดต
1. เปิดสเปรดชีตตามรหัสด้านบน และตรวจสอบว่าบัญชีที่จะใช้ติดตั้งมีสิทธิ์แก้ไขไฟล์
2. เปิดเมนู Extensions > Apps Script ในโปรเจกต์ที่ผูกกับชีต
3. วางโค้ดจาก Code.gs ในไฟล์สคริปต์ สร้างไฟล์ HTML ชื่อ `index` แล้ววางเนื้อหาจาก index.html จากนั้นไปที่ Project Settings เปิดตัวเลือก `Show "appsscript.json" manifest file in editor` และกำหนดค่าตาม appsscript.json
4. บันทึกโปรเจกต์ และอนุญาตให้สคริปต์เข้าถึง Spreadsheet เมื่อระบบร้องขอ
5. ไปที่ Deploy > Manage deployments เลือก deployment เดิม กด Edit เลือก New version แล้วกด Deploy
6. เปิด URL เว็บแอป ระบบจะแสดงหน้าแอปและเชื่อมต่อกับ Google Sheets ผ่าน Apps Script

หากสร้าง deployment ใหม่และได้รับ URL ใหม่ ให้บันทึก URL นั้นไว้แทน URL ปัจจุบัน ระบบไม่ต้องกำหนด URL เพิ่มใน index.html

เมื่อเริ่มใช้งานครั้งแรก ระบบจะสร้างแท็บ Households, Hepatitis, Pets และ CommunitySurveys หากยังไม่มี หากพบหัวตารางไม่ตรงกับรูปแบบที่กำหนด ระบบจะแจ้งข้อผิดพลาดและไม่เขียนทับข้อมูลเดิม

## สิทธิ์และการคุ้มครองข้อมูล
ข้อมูลสุขภาพและข้อมูลที่ใช้ระบุตัวบุคคลถือเป็นข้อมูลอ่อนไหว ควรจำกัดสิทธิ์เข้าถึงทั้งเว็บแอปและ Google Sheets ให้เฉพาะบัญชีหรือโดเมนที่ได้รับอนุญาต ห้ามตั้งสิทธิ์เว็บแอปเป็น Anyone (ทุกคน) เมื่อนำไปใช้กับข้อมูลจริง

หน้าเว็บนี้ไม่มีระบบล็อกอินแยกต่างหาก ผู้ใช้จะเข้าถึงข้อมูลได้ตามสิทธิ์ที่กำหนดไว้ในการติดตั้ง Google Apps Script การเปิดไฟล์ index.html โดยตรงหรือผ่านเว็บโฮสต์ภายนอกจะไม่เชื่อมต่อกับ Apps Script ต้องเปิดผ่าน URL ของเว็บแอป

## ความสามารถ
- แสดงภาพประกอบเวกเตอร์สีสันสดใสบนหน้าแดชบอร์ดและแบบสำรวจ โดยฝังไว้ใน HTML เพื่อไม่ต้องพึ่งไฟล์ภาพหรือลิงก์ภายนอก
- แสดงสรุปจำนวนครัวเรือนและกลุ่มสุขภาพสำคัญ
- บันทึกข้อมูลครัวเรือน พร้อมตรวจรหัสซ้ำ พิกัด และจำนวนสมาชิก
- กรอกแบบสำรวจชุมชนจากแบบฟอร์ม PDF ครอบคลุมประเภท/รายได้ครัวเรือน ทะเบียนสมาชิก สุขภาพรายบุคคล การคัดกรอง NCD พฤติกรรมสุขภาพ สิ่งแวดล้อม อาหาร สุขภาพแม่และเด็ก และการเข้าถึงบริการ
- เพิ่มข้อมูลสมาชิกได้หลายคน แบบสำรวจที่บันทึกจะเก็บรายละเอียดคำตอบไว้ในแท็บ CommunitySurveys และอัปเดตสรุปครัวเรือนเพื่อใช้ติดตามและปักหมุดบนแผนที่
- ติดตามสถานะการสำรวจ
- บันทึกผลคัดกรองและการติดตามไวรัสตับอักเสบ B/C
- บันทึกข้อมูลสัตว์เลี้ยงและการได้รับวัคซีน
- ส่งออกข้อมูลทั้งหมดเป็น Word (.doc), Excel (.xlsx) และรายงานสำหรับพิมพ์หรือบันทึกเป็น PDF โดยรวมคำตอบแบบสำรวจชุมชน ข้อมูลครัวเรือน ผลคัดกรอง และสัตว์เลี้ยง
- แสดงแผนที่ถนนพร้อมหมุดครัวเรือนจากพิกัดในชีต
- ขอพิกัด GPS เมื่อกดปุ่มตำแหน่งปัจจุบัน และเลือกจุดบนแผนที่หรือเลื่อนหมุดเพื่อปรับตำแหน่ง
- บันทึกพิกัดให้ครัวเรือนเดิมได้โดยไม่แก้ข้อมูลช่องอื่น หรือส่งพิกัดไปใส่แบบฟอร์มสำหรับครัวเรือนใหม่
- ใช้ Google Sheets เป็นแหล่งจัดเก็บข้อมูลหลัก

การใช้ตำแหน่ง GPS ต้องได้รับอนุญาตจากผู้ใช้ในเบราว์เซอร์ หาก Apps Script จำกัดสิทธิ์ระบุตำแหน่ง ให้คลิกเลือกตำแหน่งบนแผนที่แทน พื้นหลังแผนที่โหลดจาก OpenStreetMap; ผู้ให้บริการแผนที่จะเห็นคำขอโหลดแผนที่ตามบริเวณที่เปิดดู แต่ระบบไม่ส่งรหัสครัวเรือนหรือข้อมูลในชีตไปให้ผู้ให้บริการ

การส่งออก Excel ใช้ SheetJS จาก CDN ทางการและต้องเชื่อมต่ออินเทอร์เน็ต ส่วนไฟล์ส่งออกจะถูกดาวน์โหลดหรือพิมพ์จากเบราว์เซอร์ ไม่สร้างไฟล์สำเนาค้างไว้ใน Google Drive

ระบบไม่แสดงหรือส่งออกข้อมูลจากแท็บ ProjectProposals ที่อาจเหลือจากเวอร์ชันก่อนหน้า และจะไม่ลบข้อมูลในแท็บนั้นโดยอัตโนมัติ

เปิดเมนู “ส่งออกข้อมูล” แล้วเลือก Word หรือ Excel เพื่อดาวน์โหลดไฟล์ หากเลือก PDF ระบบจะเปิดหน้าต่างพิมพ์ ให้เลือก “บันทึกเป็น PDF” ในปลายทางของเครื่องพิมพ์

หมายเหตุ: การเชื่อมต่อกับ JHCIS ต้องได้รับอนุญาตจากหน่วยบริการ และต้องกำหนดสิทธิ์กับรูปแบบการแลกเปลี่ยนข้อมูลก่อน
